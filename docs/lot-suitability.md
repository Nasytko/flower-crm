# Срок пригодности партий (usableUntil)

## Поля

| Сущность | Поле | Смысл |
|----------|------|--------|
| `SupplyItem` | `usableUntil` | Указывается при приёмке (опционально) |
| `StockLot` | `usableUntil` | Копируется с позиции поставки при проведении |

## Политика для `null` (срок неизвестен)

**`null` не означает «бесконечная пригодность».**

Если срок не указан, для **обещания резерва** и проверки пригодности к дате выполнения заказа используется консервативная оценка:

```
effectiveUsableUntil = calendarDate(receivedAt) + UNKNOWN_LOT_SHELF_DAYS
```

Константа `UNKNOWN_LOT_SHELF_DAYS = 3` (в `@erp/shared`).

Следствия:

- Недатированную партию нельзя обещать заказу с датой выполнения позже этого окна.
- Явно указанный `usableUntil` всегда важнее оценки.
- Физический отбор при сборке по-прежнему FEFO; среди партий без даты приоритет по `receivedAt`.
- Оценка **не записывается** в БД — только при расчётах.

## UI

- В поставке: поле «Годен до» на строке.
- В расшифровке склада: показывать дату или «не указан (оценка: …)».
